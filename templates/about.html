HealthPredict AI

Patient Health Prediction & Management System

HealthPredict AI is a full-stack Python healthcare web application built for the technical assessment for the position of AI Growth & Automation Associate at Gokul Infocare. The system provides complete CRUD management of clinical patient data, multi-layer validation, and integration with the Google Gemini API for automated, educational health interpretations of blood test markers.

Key System Capabilities
Persistent SQLite Storage

Robust persistence with SQLAlchemy ORM, parameterized queries, and automatic table creation.

Multi-Layer Validation

Strict backend and frontend validation covering calendar date logic, future dates, email syntax, and clinical ranges.

External Gemini AI Service

Secure API integration using environment variables, privacy preservation (no PII sent), and zero fabricated responses.

API Call Optimization

During patient edits, AI analysis is only re-triggered if blood markers change, saving quota and response latency.
